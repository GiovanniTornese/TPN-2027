Auth testing (TPN 2027)
App uses its OWN cookie session: httpOnly cookie session = JWT (HS256, sub = users.id), set by /api/auth/login, /api/auth/register and /api/auth/google (Emergent Google OAuth: frontend redirects to https://auth.emergentagent.com/?redirect=<origin>/ , returns with #session_id=..., frontend POSTs it to /api/auth/google which calls Emergent session-data server-side and finds-or-creates the user by email). Users: {id, email, password_hash ("" for Google-only), role admin|volunteer, first_name, last_name, phone, gender M|F|null, is_team_leader}. Google OAuth can't be automated: test with email/password accounts (see memory/test_credentials.md) or register a volunteer via /register. A Google-created volunteer has gender=null/phone="" and is redirected to /profilo to complete the profile.
